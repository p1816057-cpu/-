# 天融 SkyFusion v1.2.1

完全离线的 Windows 格式转换工具 · 音频转换 / 图片转换与压缩 · 不联网、无需安装运行时

## 本版亮点

- **输出位置重做**：默认输出到程序所在文件夹下自动创建的 `转换输出`，支持「程序所在文件夹 / 与源文件相同文件夹 / 自定义固定文件夹」三种模式
- **弹窗体验**：模态 + 主界面遮罩 + 背景虚化，提示类图标红色系；新增单实例保护，重复启动会把已打开的窗口恢复到前台
- **设置页**：操作栏常驻顶部，未改动时「保存设置」不可点击，已是默认设置时「恢复默认」只提示
- **品牌与图标**：全新程序图标（exe / 窗口 / 任务栏 / 安装包统一），标题栏与关于页启用新 Logo
- **界面文案**：左侧导航改为「图片转换、压缩」

## 系统要求

- Windows 7 SP1 x64 / Windows 10 x64 / Windows 11 x64（不支持 32 位系统）
- .NET Framework 4.8（Win10 1903+ 与 Win11 自带；Win7 需自行安装）
- Win7 还需要 KB4490628、KB4474419、KB4019990 三个系统补丁

## 详细变更

### 输出位置

- 默认输出到「程序所在文件夹」下的 `转换输出` 子文件夹，启动即建好；不再写入 `%USERPROFILE%\Music\...` 之类的固定路径
- 旧配置里残留的它机路径会自动清理（界面与 `settings.json` 同步）
- 自定义目录在本机不可用（盘符不存在）时回退到程序目录；程序目录不可写（如装在 `C:\Program Files`）时回退到源文件所在文件夹
- 转换页 / 图片转换压缩页可点「浏览…」切换自定义目录并立即保存，也可一键「改回程序所在文件夹」
- 输出目录预览改为两行小字，长路径尽量完整显示

### 弹窗与提示

- 弹窗为模态窗口并始终位于主界面之上；主界面在弹窗期间被系统禁用，避免误操作
- 弹窗出现时主界面压暗并虚化（毛玻璃），描边与投影加强，在浅色界面上清晰可辨
- 提示类（警告 / 信息）图标改为红色系，成功仍为绿色、错误为红色
- 单实例保护：同一个登录会话重复启动会提示「检测到已打开同类型软件」，确认后唤醒已打开的窗口

### 设置页

- 操作栏（导出日志 / 恢复默认 / 保存设置）固定在页面顶部常驻
- 「保存设置」随改动状态联动：无改动不可点击，保存完成或改回原值后自动变灰
- 「恢复默认」在当前已是默认设置时只提示，不再弹确认框

### 工程

- 版本号单一来源：`Common/AppInfo.cs` 从程序集读取，界面、启动日志、诊断导出统一取用
- 重构输出路径解析（`Core/OutputLocation.cs`），新增 `OutputLocationMode` 模型
