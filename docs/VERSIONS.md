# 版本记录

## v1.2.1（当前版本）

### 输出位置

- 默认输出位置改为「程序所在文件夹」：启动时自动在 `SkyFusion.exe` 所在目录新建 `转换输出` 文件夹，转换 / 压缩结果默认放在里面，音频与图片模块都适用
- 不再默认写入 `%USERPROFILE%\Music\AudioConverter` 等固定绝对路径；旧配置里的它机路径会自动清理（内存与 `settings.json` 同步）
- 设置页「输出位置」提供三种模式：程序所在文件夹（默认）/ 与源文件相同文件夹 / 自定义固定文件夹，选择保存在本机 `%APPDATA%\AudioConverter\settings.json`
- 自定义目录在本机不可用（盘符不存在）时回退到程序目录；程序目录不可写（如装在 `C:\Program Files`）时回退到源文件所在文件夹
- 转换页与「图片转换、压缩」页点「浏览…」即切换为自定义文件夹并立即保存，可一键「改回程序所在文件夹」
- 输出目录预览改为两行小字（FontSize 12 + 自动换行），长路径尽量完整显示；设置页前两种模式下方只读展示实际会用到的目录

### 弹窗与提示

- 弹窗统一为「模态 + 主窗口附属窗口」：弹窗期间主界面被系统禁用（点不动），弹窗恒在软件界面之上，用户点回软件时自动回到最前，切到其它程序时跟随一起沉下去
- 弹窗辨识度提升：主界面压暗（`Brush.ModalMask`，约 30% 黑遮罩）+ 背景虚化（`BlurEffect` 半径 8）+ 描边加深加粗（#9CA3AF / 1.5px）+ 投影加重（Blur 32 / Depth 3 / Opacity 0.22）
- 提示类（警告 / 信息）弹窗图标改为红色系，成功仍为绿色、错误为红色
- 新增单实例检测：同一登录会话重复启动时弹出「检测到已打开同类型软件」，确认后把已运行的窗口恢复到前台，第二个实例退出

### 设置页

- 操作栏（导出日志 / 恢复默认 / 保存设置）固定在页面顶部常驻，滚动设置内容时始终可见
- 「保存设置」随改动状态联动：无改动时不可点击，改动后可用，保存完成或改回原值后恢复不可点击
- 「恢复默认」在当前已是默认设置时只提示「当前已是默认设置」，不再弹确认框
- 选择「自定义固定文件夹」但未选目录时，保存会提示先选目录

### 界面与品牌

- 左侧导航与功能区文案统一改为「图片转换、压缩」（导航项、页面标题、副标题、设置页分组名）
- 新增程序图标 `src/AudioConverter/Assets/app.ico`：16/24/32/48/64 采用 DIB、128/256 采用 PNG 的七尺寸图标（白底抠透明），同时用于 exe 图标（`ApplicationIcon`）、窗口 / 任务栏图标（`MainWindow.Icon`）与安装包图标（`SetupIconFile`）；源图保存在 `assets/app-icon-source.png`
- 界面内 Logo 同步替换：标题栏左上角与「关于」页产品信息区改用 `Assets/app-logo.png`（与程序图标同源的 256×256 透明 PNG），不再使用占位音符图标

### 工程

- 版本号改为单一来源：`Common/AppInfo.cs` 从程序集 `InformationalVersion` 读取，界面、启动日志、诊断导出统一取用
- 同步更新 `docs/开发提示词.md`、`docs/ARCHITECTURE.md`、`docs/VERSIONS.md`
