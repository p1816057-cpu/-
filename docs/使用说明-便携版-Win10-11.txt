天融 SkyFusion v1.2.1 · 离线便携版（Windows 10 / 11）
=====================================================

一、怎么用
1. 把整个文件夹复制到目标电脑（U 盘直接运行也行，建议先拷到本地磁盘）；
2. 双击 SkyFusion.exe；
3. 音频转换：点「文件 → 打开音频文件…」，或把 MP3/WAV/FLAC/MP4/MKV
   直接拖进窗口 → 勾选文件 → 选输出格式 → 点「开始转换」；
4. 图片转换 / 压缩：左侧点「图片转换、压缩」→ 添加 JPG/PNG/WebP/BMP →
   选输出格式、拖画质滑块或选缩放比例，程序会实时显示压缩后预览和体积对比。

二、转换结果放在哪（v1.2.1 变化）
- 默认输出到「本程序所在文件夹」下的 转换输出 子文件夹，
  例如程序放在 D:\SkyFusion\，结果就在 D:\SkyFusion\转换输出\；
- 首次启动会自动建好这个文件夹，不再写入 %USERPROFILE%\Music 之类的固定路径；
- 想改位置：设置 → 输出位置，可选「程序所在文件夹（默认）/ 与源文件相同文件夹 /
  自定义固定文件夹」；在转换页点「浏览…」也会切换成自定义文件夹并立即保存。
- 如果程序目录没有写入权限（例如装在 C:\Program Files），会自动改用
  「源文件所在文件夹」，保证转换不失败。

三、系统要求
- Windows 10 64 位 / Windows 11 64 位（本包按此配置打包）
- 需要 .NET Framework 4.8：Win10 1903 及以后、Win11 系统自带，无需安装。
- 32 位系统不支持（主程序为 64 位）。

四、离线说明
- 全程不联网：转换只用本文件夹里的 ffmpeg\bin\ffmpeg.exe，
  不下载任何东西、不写注册表、无后台服务。
- 设置与历史记录保存在 %APPDATA%\AudioConverter\，每台电脑各自独立。
- 同一个 Windows 登录会话只允许开一个程序：重复双击时会提示
  「检测到已打开同类型软件」，确认后会把已经打开的窗口恢复到前台。

五、文件清单
- SkyFusion.exe / SkyFusion.exe.config        主程序
- ffmpeg\bin\ffmpeg.exe                       转换核心（FFmpeg 7.0 静态版）
- ffmpeg\bin\ffprobe.exe                      媒体信息探测
- 转换输出\                                   默认输出目录（首次启动自动创建）
- FFmpeg-LICENSE.txt / FFmpeg-README.txt      FFmpeg 许可与说明
- LICENSE / THIRD-PARTY-NOTICES.md           本软件许可与第三方声明

六、常见问题
- 被杀软拦下：本程序未做数字签名，个别安全软件会误报（只调用本机 FFmpeg），
  点「仍要运行 / 允许」即可，也可以把整个文件夹加入白名单。
- 双击没反应：确认系统是 64 位，且 .NET Framework 4.8 已就绪。
- 重复打开只弹提示：这是单实例保护，不是故障；点确定后会用已经打开的窗口继续。
- 转 MP4/MKV 时程序会先提取音轨再转，属正常行为。

七、关于 Windows 7
Win7 SP1 64 位同样可以跑，但目标机器需要额外准备：
1) .NET Framework 4.8 离线安装包；
2) 系统补丁 KB4490628（服务堆栈）、KB4474419（SHA-2 签名支持）；
3) KB4019990（WPF 界面依赖的 d3dcompiler_47）。
需要的话可以再单独打包一份 Win7 完整离线版，把上面这些一起放进去。
